## 🚀 Featured projects

### 🎮 [Fieldwork · Minesweeper](https://github.com/Sathvik18M/DSA_MINIPROJECT)

A responsive browser game with three difficulty levels, keyboard and touch controls, safe first moves, and saved personal bests. Its game logic uses a two-dimensional array and breadth-first flood fill.

**Built with:** JavaScript · HTML · CSS  
**Explore:** [Play the game](https://Sathvik18M.github.io/DSA_MINIPROJECT/) · [View source](https://github.com/Sathvik18M/DSA_MINIPROJECT)

### 💬 [RescueLoop AI](https://github.com/Sathvik18M/RESCUELOOP-AI)

A seller support portal with a WhatsApp customer interface. The project brings together support conversations, requests, policies, and insights in a web dashboard, with AI-assisted workflows and seller review.

**Built with:** Next.js · TypeScript · Tailwind CSS · Python · FastAPI · PostgreSQL · Supabase  
**Explore:** [View the project](https://github.com/Sathvik18M/RESCUELOOP-AI)

### 🌐 [Portfolio Workshop](https://github.com/Sathvik18M/My_test_profile)

A portfolio learning project based on the GDG workshop starter, using React and Vite to explore component-based web development.

**Built with:** React · JavaScript · Vite · CSS  
**Explore:** [View the project](https://github.com/Sathvik18M/My_test_profile)
